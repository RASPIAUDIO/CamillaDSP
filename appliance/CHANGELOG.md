# RASPIAUDIO CamillaDSP Box Changelog

## 2026.06.29

- Added the beginner dashboard flow: hardware detected, USB audio, audio test.
- Added the default `PC USB 7.1 to 8 analog outputs` mode.
- Added hidden advanced modes for TOSLINK stereo, active crossover, analog input test, and CamillaGUI.
- Added `Fix audio` to restart the USB gadget, CamillaDSP, and TOSLINK driver path.
- Added RASPIAUDIO 8xOUT and 8xIN+8xOUT auto-detection.
- Added GPIO12 optical TOSLINK support through the `RASPISPDIF` driver.
- Added release validation and diagnostics zip support.
