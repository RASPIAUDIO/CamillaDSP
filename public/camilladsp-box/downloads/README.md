# Downloads

Place validated release images here before publishing the public page:

```text
raspiaudio-dspbox-pi5-YYYY.MM.DD.img.xz
raspiaudio-dspbox-pi5-YYYY.MM.DD.img.xz.sha256
```

Do not publish a file here until the image has passed the fresh-flash release
checklist in `docs/appliance_image.md`.
